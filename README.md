# Homebrew ksamint tap

Public Homebrew casks for ksamint macOS applications.

## ksamint MarkEdit

After the signed and notarized release is published:

```sh
brew install --cask fengurt/ksamint/ksamint-markedit
open -a "ksamint MarkEdit"
```

The cask supports Intel and Apple silicon Macs running macOS 15 or later.
Source, release notes, and localization review live in
[fengurt/ksa-MarkEdit](https://github.com/fengurt/ksa-MarkEdit).
